# Setup interview

Ask only what is missing or older than the user would trust (for example salary floors after six months). Batch related questions; offer sensible options and always allow free text. Write each answer as soon as it is given.

## 1. Identity and contact → profile.md
- Full name as on the CV; city and country of residence; phone; email; website; GitHub; LinkedIn.
- Citizenship(s). (Drives visa routes and NATO/EU-citizen filters.)
- Languages with levels (CEFR where possible) and any certificates.
- Words, employers or projects never to mention in any document.

## 2. Targets → preferences.md
- Tracks: the kinds of roles wanted (propose groups from the CV, e.g. web, DevOps, Rust/embedded). One CV per track will be built.
- Level per track (junior, mid, senior; years range) and what is a stretch.
- Excluded role types (internships, working student, agencies, ...).
- Languages and stacks that count as a match; stacks to avoid (e.g. "C/C++-first roles").
- Regions in priority order; whether location filters or only ranks; remote rules.
- Visa rule: reject roles that state no sponsorship, or apply anyway? (Record the user's exact rule.)
- Industries preferred or excluded (e.g. defence: excluded / allowed / preferred).

## 3. Application answers → preferences.md "Application answers"
- Earliest start date and notice period.
- The one-line answer to "Do you need visa sponsorship?" per country group.
- Salary floors: ask for the floor where they live (remote) and in their top country; calculate the others (cost of living, visa salary thresholds) and show the table for confirmation. Warn when a floor sits below a visa threshold or the local minimum wage.
- Degree status and how to state it.

## 4. References → preferences.md "References"
- For each: full name, role, relationship (manager, colleague, client), company, email, phone, and whether they agreed. Ask before first use if any field is missing.

## 5. Documents (checklist, not files) → profile.md "Documents"
- Passport validity; degree certificate, transcript, diploma supplement; translations/apostilles; degree recognition (e.g. Germany: anabin / ZAB statement); employment reference letters; language certificates. Record status and dates, never document numbers.

## 6. Profiles → run the audit mode
- GitHub login and LinkedIn URL; then run `audit` and save the checklist to `DATA/profile-audit.md`.
